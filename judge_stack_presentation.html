🔬 Optical Sensing Principles
  • 660 nm (Red Peak): Coincides with the peak optical absorption of Chlorophyll a and b $Q_y$ band. High foliar chlorophyll strongly absorbs this wavelength.
  • 880 nm (NIR Plateau): Chlorophyll is completely transparent to near-infrared radiation. Light transmission is governed strictly by the refractive index transitions between cell walls and air cavities within the spongy mesophyll.
  • NDVI Formulation: NDVI = (I_880 - I_660) / (I_880 + I_660)
  • SPAD Proxy: SPAD = 10.0 * ln( (I_880/I_0,880) / (I_660/I_0,660) )
⚙️ Edge MicroPython Driver
  • Non-blocking SoftI2C on GPIO 4 (SDA) and GPIO 5 (SCL) running at 100 kHz.
  • Internal ADC Rate: 100 Hz sampling with 8x hardware FIFO averaging (effective 12.5 sps) for high signal-to-noise ratio.
  • Dynamic Optical Guards: Automatic detection of ambient saturation (>255,000 counts) and empty air (<1,000 counts).
  • HiveMQ TLS with SNI: Patched umqtt.simple passing server_hostname to authenticate with HiveMQ Cloud clusters.

🔍 The Multicollinearity Challenge

Simple linear formulas like SPAD are sufficient only for gross chlorophyll. However, the plant ionome (N, P, K, Ca, Mg) exhibits overlapping spectral absorption and structural scattering effects. Potassium (K) controls cell turgor and moisture boundaries, modifying 880nm scattering; Calcium (Ca) cross-links pectin in cell walls, changing tissue refractive index; Magnesium (Mg) coordinates the chlorophyll porphyrin ring while affecting starch translocation. To decouple these collinear factors, we apply Partial Least Squares Regression (PLSR).

📐 Mathematical Preprocessing Sequence
  • Standard Normal Variate (SNV): x_SNV = (x - mean(x)) / std(x)
    Normalizes each spectrum to zero mean and unit variance, eliminating leaf thickness and distance baseline shifts.
  • Multiplicative Scatter Correction (MSC): Regresses each spectrum against a reference standard to remove additive and multiplicative light scattering.
  • Savitzky-Golay 2nd Derivatives: Computes polynomial convolution weights to eliminate linear drift and sharpen overlapping absorption shoulders.
📊 PLSR Latent Variable Projection
  • Decomposes spectral matrix X = T P^T + E and concentration matrix Y = U Q^T + F.
  • The NIPALS algorithm maximizes the covariance between score vectors T and U.
  • Produces regression matrix B_PLS = W (P^T W)^-1 Q^T that outputs discrete nutrient percentages directly from optical inputs.

🤖 n8n Workflow & pgvector Architecture

Generic LLMs frequently hallucinate fertilizer dosages. Our architecture eliminates hallucination using an automated n8n workflow backed by PostgreSQL with pgvector:

  • Event Ingestion in n8n: n8n receives incoming MQTT sensor packets or webhook payloads and triggers upon detecting a deficient foliar element.
  • pgvector Semantic Retrieval: PostgreSQL with pgvector indexes all 1,338 TNAU records using vector embeddings. Executes hybrid cosine distance search combined with exact metadata filtering on crop and nutrient.
  • Context Injection: n8n constructs a strictly bounded prompt with TNAU context, preventing the LLM from inventing dosages.
  • Instant Advisory Delivery: Outputs exact soil split schedules (kg/ha) and foliar dilution ratios (% and g/L) directly to the mobile dashboard.
📱 Android Mobile & Cloud Stack
  • HiveMQ Cloud TLS 8883 MQTT with SNI hostname routing for edge nodes.
  • WebSockets Port 8884 for real-time frontend subscriptions via mqtt.js.
  • Sub-200ms Latency: Edge FIFO (80ms) + TLS MQTT (94ms) + PLSR/RAG (18ms) = 192.7ms total.
  • Mobile UI (index.html): Live NDVI/SPAD dials, packet rate counters, and Android WebView compatibility.
